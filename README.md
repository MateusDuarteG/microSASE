# microSASE - Secure Access Service Edge (Simulado)

O **microSASE** é uma solução simplificada inspirada no conceito de Secure Access Service Edge (SASE), unindo controle de acesso seguro, regras de política de rede e telemetria de conexões em tempo real.

## 🚀 Funcionalidades

- **API REST**: Controle e gerenciamento de políticas de acesso/bloqueio.
- **Modo Simulação**: Execução em ambiente de desenvolvimento (Windows/Linux) sem depender do WireGuard real.
- **Dashboard Interativo**: Visualização de conexões e tráfego em tempo real via Streamlit.
- **Suporte a Container**: Imagem Docker pronta para deploy em Linux com suporte a interfaces de rede.

## 🛠️ Tecnologias Utilizadas

- **Linguagem**: Python 3.10+
- **API Framework**: FastAPI / Flask
- **Interface**: Streamlit
- **Containerização**: Docker / Docker Compose
